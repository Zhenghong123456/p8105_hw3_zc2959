## NY NOAA Data Description

1.  The `ny_noaa` dataset contains 2,595,176 daily observations from 747
    stations (1981–2010), with seven variables: `id`, `date`, `prcp`,
    `snow`, `snwd`, `tmax`, and `tmin`.

2.  Missing rates are highest for `tmax` and `tmin` (43.71% each),
    followed by `snwd` (22.80%), `snow` (14.69%), and `prcp` (5.62%).
    Station IDs and dates are complete.

## Data Cleaning

``` r
ny_noaa_clean =
  ny_noaa |>
  separate(
    date,
    into = c("year", "month", "day"),
    sep = "-",
    remove = FALSE,
    convert = TRUE
  ) |>
  mutate(
    tmax = as.numeric(tmax) / 10,
    tmin = as.numeric(tmin) / 10,
    prcp = prcp / 10,
    snow = snow / 10,
    snwd = snwd / 10
  )
```

1.  **Data cleaning:** The date was separated into numeric `year`,
    `month`, and `day` variables. Temperatures were converted to degrees
    Celsius, precipitation to millimeters, and snowfall and snow depth
    to centimeters.

2.  **Snowfall:** The most common value is 0 cm. Common positive values
    include 1.3, 2.5, and 5.1 cm, consistent with measurements in
    approximate half-inch and whole-inch increments.
